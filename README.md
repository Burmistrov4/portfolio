# Portfolio — Lorenzo Roca

Portafolio interactivo de Ingeniería en Sistemas, Desarrollo Full-Stack y Soporte TI ([lorenzoroca.vercel.app](https://lorenzoroca.vercel.app)).

- **Frontend 3D + SSR**: Next.js 14 (App Router), TypeScript, Tailwind CSS 4, Three.js + GLSL shaders con vista rápida 2D accesible y soporte bilingüe (`ES / EN`).
- **Backend & CMS**: Supabase (PostgreSQL, Storage, Auth) + Route Handlers autenticados + Gemini API.
- **Documentación & CV-as-Code**: ver [docs/README.md](./docs/README.md).

## Scripts principales

```bash
npm run dev      # Desarrollo local
npm run lint     # ESLint
npm run build    # Build de producción
```

# Documentación Técnica Centralizada

Este directorio consolida los artefactos de documentación del proyecto:

| Área | Tecnología | Ubicación |
| :--- | :--- | :--- |
| **Arquitectura visual** | Diagramas vectoriales SVG y fuentes editables | `docs/architecture/` y `public/diagrams/` |
| **Currículum ATS** | YAML validado + Typst via `rendercv` | `docs/cv/` y `public/cv/` |
| **Fichas de proyectos** | TypeScript tipado (`ProjectDetail`) | `lib/project-details.ts` |
| **Reglas de calidad** | ESLint + TypeScript `strict` | `.eslintrc.json`, `tsconfig.json` |
